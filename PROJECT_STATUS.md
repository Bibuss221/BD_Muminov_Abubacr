# Статус проекта

Репозиторий содержит клиентское C++/Qt 6 приложение и PostgreSQL-часть курсового проекта.

SQL разделён по назначению: схема, триггеры, функции, представления, индексы, роли, тестовые данные и проверки.

В состав клиентской части входят подключение через QPSQL, Model / Controller / View, таблицы клиентов, автомобилей, сделок, скидок и штрафов, а также агрегированный отчёт.

Полную сборку Qt 6 + QPSQL необходимо проверить локально на Windows.
