# Статус проекта

Готовая заготовка репозитория для загрузки в GitHub.

## Содержит

- PostgreSQL schema/triggers/views/indexes/roles/seed/drop;
- Qt6/C++17 application;
- MVC-like разделение;
- role detection through PostgreSQL;
- basic CRUD operations;
- Qt Test;
- PlantUML diagrams;
- PowerShell scripts;
- documentation.

## Что нужно проверить на компьютере

1. Qt 6 + QPSQL.
2. PostgreSQL.
3. CMake + Ninja.
4. Выполнить `scripts\setup_database.ps1`.
5. Собрать проект.
6. Проверить подключение в приложении.
7. Сменить демонстрационные пароли перед реальным использованием.
