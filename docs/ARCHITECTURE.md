# Архитектура

Клиентская часть проекта разделена на Model / Controller / View.

Model — структуры предметной области, соединение с PostgreSQL и репозитории.
Controller — сценарии взаимодействия между интерфейсом и моделью.
View — окна Qt Widgets и табличные представления.
app — точка входа приложения.

Серверная часть PostgreSQL вынесена в отдельный каталог database:
схема, триггеры, функции, представления, индексы, роли и тестовые данные.
