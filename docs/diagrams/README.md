# Диаграммы

Исходники диаграмм хранятся в формате PlantUML:

- `er_model.puml` — сущности и связи БД;
- `use_case.puml` — роли и варианты использования;
- `sequence.puml` — запрос от View через Controller к PostgreSQL;
- `architecture.puml` — MVC и БД;
- `class_model.puml` — основные классы клиентской части.

Диаграммы намеренно лежат исходниками, чтобы их можно было заново построить, а не хранить только картинку.
