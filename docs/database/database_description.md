# Описание базы данных

Клиент связан со сделками. Автомобиль связан со сделками. Сделка может иметь штрафы и применённые скидки. Ограничения NOT NULL, UNIQUE, CHECK и внешние ключи обеспечивают целостность.

Бизнес-правила: автомобиль не может иметь пересекающиеся периоды аренды; даты возврата не могут нарушать период сделки.
